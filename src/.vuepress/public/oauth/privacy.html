隐私政策 / Privacy Policy

sch246-drive · 最后更新 2026-11-19

1. 适用范围

本政策适用于 sch246-drive（下称“本应用”）。本应用是运行在开发者本人电脑上的开源命令行工具 rclone 的私有 OAuth 客户端配置，仅供开发者本人使用：不对外提供服务、不注册用户、没有任何后端服务器或数据库。

2. 收集哪些信息

不收集任何个人信息。本应用没有分析埋点、没有遥测、没有日志上报。开发者作为唯一使用者，其数据也仅存在于其本机与自己的 Google Drive 之间。

3. 如何访问 Google 用户数据

经使用者授权后，本应用通过 Google Drive API 访问使用者本人的 Drive 文件，范围仅限于：

  • https://www.googleapis.com/auth/drive —— 列出、下载、上传本人 Drive 中的文件，创建目录。

用途单一：把本机生成的文件备份到本人 Drive 并在需要时取回。不读取 Gmail、日历、联系人、照片等其他 Google 服务的数据，不访问他人的 Drive。

4. 有限使用声明（Limited Use）

本应用对从 Google API 获取的信息的使用，遵守 Google API 服务用户数据政策（Google API Services User Data Policy），包括其有限使用（Limited Use）要求。具体而言：

  • 仅将 Google 用户数据用于提供本政策第 3 条所述的、面向用户可见的文件同步功能；
  • 不将 Google 用户数据传输给第三方，不出售、不出租、不用于广告；
  • 不使用 Google 用户数据训练、改进或开发任何机器学习或人工智能模型；
  • 不允许人工读取 Google 用户数据，除非获得用户对特定文件的明确同意、为安全目的（如调查滥用）所必需，或法律要求；
  • 不使用 Google API 生成、处理或传播 AI NCII（未经当事人同意生成的私密图像）或任何类似内容；本应用不具备生成图像的能力，只做文件搬运。

5. 凭据如何存储

OAuth 访问令牌与刷新令牌保存在本机文件 ~/.config/rclone/rclone.conf（文件权限 600，仅本机当前用户可读）。凭据不经网络上传，不由任何第三方持有。所有与 Google 的通信均为 HTTPS 直连。

6. 数据共享与转移

不向任何第三方出售、出租、共享或转移 Google 用户数据。本应用不存在广告、追踪、画像或数据经纪行为。

7. 保留与删除

本应用不在云端保留任何数据副本。本机配置与日志可随时删除：rm -rf ~/.config/rclone。已上传到 Drive 的文件由使用者自行在 Drive 中管理。撤销授权后，本应用立即失去访问能力。

8. 撤销授权

前往 Google 账号 → 安全性 → 第三方应用和服务的访问权限，移除 sch246-drive 即可。

9. 政策变更

如本政策变更，将更新本页顶部日期。本应用为个人自用工具，变更通常仅涉及措辞澄清。

English summary. sch246-drive is a private OAuth client configuration for the open-source tool rclone, used by a single person on their own computer. It has no backend server and collects no personal data. With the user's consent it accesses only that user's own Google Drive via https://www.googleapis.com/auth/drive to list, download and upload files. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is not sold, transferred to third parties, used for advertising, or used to train machine learning models. The app does not use Google APIs to generate or process AI NCII. Tokens are stored locally in ~/.config/rclone/rclone.conf. Access can be revoked anytime at myaccount.google.com/permissions. Contact: fmyzc233@gmail.com.
